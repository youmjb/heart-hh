# 활동전압 시뮬레이션 (Hodgkin–Huxley)

생리학 실습용 **활동전압 시뮬레이터**와 **실습 매뉴얼**입니다.
브라우저에서 바로 돌아가며, 설치·서버·로그인·인터넷 연결이 필요 없습니다.
계산은 전부 브라우저 안에서 이루어집니다.

| | |
|---|---|
| 시뮬레이터 | `index.html` |
| 실습 매뉴얼 | `manual.html` |
| 오프라인용 단일 파일 | `heart_hh_standalone.html` |

## 쓰는 법

**웹에서** — 공개된 주소를 열면 끝입니다. 상단의 **📖 실습 매뉴얼** 버튼으로
매뉴얼이 열립니다.

**오프라인에서** — `heart_hh_standalone.html` 하나만 내려받으면 됩니다.
모든 코드와 파라미터가 그 파일 안에 들어 있어 더블클릭하면 똑같이 동작합니다
(강의장 네트워크를 믿을 수 없을 때 권합니다).

휴대폰·태블릿에서도 열립니다. 화면이 좁으면 그래프 아래로 설정 패널이 이어지는
한 줄 배치로 바뀝니다. 다만 그래프를 읽고 커서로 값을 재야 하므로 실습 자체는
노트북 화면이 수월합니다.

## 실습 내용

매뉴얼은 11개 항목으로 되어 있고, 각 항목마다 개념 소개 → 설정 → 절차 →
질문 순서로 적혀 있습니다. 프로그램의 **실습 항목** 드롭다운에서 항목을 고르면
자극 프로토콜·채널 설정·모드·표시범위·표시할 전류가 한 번에 맞춰집니다.

| | |
|---|---|
| **I. 활동전압 (1)** | 단일 활동전압과 실무율, 불응기 |
| **II. 전압고정** | INa activation / inactivation, IK activation, 시간상수 τ, α·β, 활동전압 재구성 |
| **III. 활동전압 (2)** | 역치전류와 strength–duration 곡선 (rheobase·chronaxie), 순응, anodal break |

손으로 재는 절차와 함께, 반복 측정이 필요한 세 가지는 자동 측정 기능을
넣었습니다 — **강도–지속시간 곡선**, **IK 시간상수 τ 와 α_n·β_n**,
**활동전압 재구성**. 자동 측정은 결과만 내놓지 않고 *측정값이 이론값과 왜 다른지*
까지 각 패널의 접이식 설명에 적어 두었습니다.

측정 결과는 **CSV**(측정표·곡선), **PNG**(그래프), **TXT**(전체 시계열)로
내보낼 수 있습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구성과 스타일, 시뮬레이터 본체 |
| `js/model.js` | 시뮬레이션 엔진 (HH 모델 + 심근세포 모델) |
| `js/graph.js` | 캔버스 그래프 (격자·축·눈금) |
| `js/app.js` | UI, 실행 루프, 커서·측정표·자동 측정 |
| `js/params.js` | 실습용 파라미터(자극 프로토콜·채널 배율·이온농도) 내장 |
| `js/strengthduration.js` | 강도–지속시간 곡선 계산 (화면 없이 반복 시뮬레이션) |
| `js/reconstruct.js` | 활동전압 재구성 — α·β 와 막방정식만으로 적분 |
| `manual.html` | 실습 매뉴얼 (인쇄·PDF 저장용 서식 포함) |
| `heart_hh_standalone.html` | 위 전부를 한 파일로 합친 오프라인판 |
| `build_standalone.py` | 단일 파일 빌드 스크립트 |
| `gen_params.py` | 파라미터 파일에서 `js/params.js` 재생성 |

## 고칠 때

`index.html` 과 `js/` 를 고친 뒤 단일 파일을 다시 만듭니다.

```bash
python build_standalone.py
```

`index.html` 과 `heart_hh_standalone.html` 은 **같은 내용**이어야 하므로,
고친 뒤에는 반드시 다시 빌드해 두 파일을 함께 커밋하세요.

프로그램 안에서 `.prm .sfs .ion .con` 파일을 직접 불러올 수도 있습니다
(**파일 불러오기**). 파라미터 파일 모음이 따로 있다면 `gen_params.py` 로
`js/params.js` 를 다시 만들면 됩니다.

## 모델

막전류는 Hodgkin–Huxley 형식으로 계산합니다.

```
dx/dt = α(V)(1−x) − β(V)x          x = m, h, n
I_Na  = ḡ_Na · m³h · (구동력)
I_K   = ḡ_K  · n⁴  · (구동력)
C · dV/dt = −Σ I + I_stim
```

구동력은 옴형 `(V − E)` 와 정전장(GHK) 두 가지를 쓸 수 있습니다.
차이와 선택 기준은 매뉴얼 **부록 A — 구동력** 에 설명해 두었습니다.
시간간격은 막전위 변화 속도에 따라 자동으로 조절되며 고정할 수도 있습니다.

## GitHub Pages 로 올리기

이 폴더의 내용을 저장소 루트에 그대로 올리고, **Settings → Pages** 에서
Source 를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)` 로 지정합니다.
1~2분 뒤 다음 주소에서 열립니다.

```
https://<사용자이름>.github.io/<저장소이름>/
```

모든 링크가 상대경로라 저장소 이름이 붙은 하위 경로에서도 그대로 동작합니다.
`.nojekyll` 은 GitHub 이 파일을 Jekyll 로 다시 처리하지 않고 그대로 내보내도록
하는 표시입니다 — 지우지 마세요.
